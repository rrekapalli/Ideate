Security

Current lab topology, not a SOC 2 report.

  • The Angular app, Java API, and this website run in unprivileged Proxmox LXC containers on a local host, reached over Tailscale MagicDNS.
  • The app and this site terminate HTTPS with Tailscale-issued certificates when that setup succeeds.
  • Postgres is a shared operator database on the tailnet (pg18), not a laptop-local instance.
  • Sign-in is disabled in this deploy. Anyone who can reach the app URL can use it. Treat the tailnet as the access control.
  • This static site is nginx only. It does not proxy /v1 to the API.

If you find a problem on these hosts, use Contact.
