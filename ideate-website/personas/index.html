Lenses, not products

Personas

The operating system, object model, and lifecycle stay the same. What changes is the objective, the default question, and the collaborator’s posture.

Personas attach to a workspace, not to the account. Signup does not ask for one. You must choose one to create a project. You can change it later on that workspace.

Student

Grow understanding. Success is a visible conceptual model, with misconceptions kept as history rather than silently overwritten.

Researcher

Make a defensible claim and revise it. Success looks like confidence, contradictions, citations, theory versions, and a review pass before you write.

Inventor

Make something work. Success looks like decisions, constraints, calculation chains, and targets kept distinct from measured facts.

Analyst

Choose under uncertainty. Success is a traceable reason for a decision, and the ability to replay it months later.

Explorer

Follow curiosity. Success is open questions preserved, and speculation that stays tagged instead of hardening into a fake conclusion.

Same loop

Think → Explore → Connect → Question → Test → Revise → Create. A student wonders why, a researcher suspects that, an inventor asks what if we built. Scientist is not a sixth persona; that work uses Researcher.
