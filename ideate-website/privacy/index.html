Privacy

This page describes the current lab deployment. It is not a consumer product privacy policy for a public SaaS.

Workspace objects, chat transcripts, attachments metadata, and reports live in the operator’s PostgreSQL database (Apache AGE and pgvector) behind the Java API. Files attached to cards are stored by that API.

Account sign-in is off in this deploy (IDEATE_AUTH_ENABLED=false). Do not put secrets or other people’s private records into a shared lab workspace.

When an Explore or other chat turn runs, the configured model backend may receive workspace text, including card titles, bodies, and recent transcript. That backend may be a local Ollama or LM Studio URL, or a cloud API the operator configured. Ideate does not run ads and does not sell workspace data.

This marketing site is static files. It does not set an account cookie and does not send pages to an analytics vendor. See Cookies.
