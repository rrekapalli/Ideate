Features

This page describes behavior in the running Angular workspace and Java graph API. It does not sell work that is still a presentation gap.

Workspace

  • One workspace equals one project. There is no default workspace after you open an account.
  • Creating a workspace requires a persona: Student, Researcher, Inventor, Analyst, or Explorer.
  • The shell is a three-column thinking IDE: objects / documents / branches on the left, graph and tabs in the center, chat on the right, timeline and related tools below.

Objects and graph

  • First-class cards include Thought, Concept, Unknown, Question, Hypothesis, Assumption, Evidence, Experiment, Observation, Claim, Critique, Decision, Evaluation, Theory, Misconception, Constraint, Calculation, Target, Design Artifact, Architecture, Component, and Citation.
  • A Theory cannot be created except from an Evaluation (or from an existing Theory).
  • Categories include active, abandoned, misconception, supported, speculative, and unknown.
  • Edges include contradicts, abandoned-because, resurrected-as, reused-in, calculated-from, version-of, overlay-on, and promoted-to.
  • The canvas is zoomable. Compact cards sit on the graph; opening one is a full page.

Chat and modes

  • The entire conversation is persisted.
  • Explore talks into the structure and materializes objects as the conversation happens. You can override: edit, demote, delete a junk batch, merge, undo.
  • Nine modes stay in the dropdown: Explore, Learn, Challenge, Research, Create, Review, Explain, Debate, Practice. Review is treated as a deep job. Modes do not change the menus.

Branches, files, search, reports

  • Create a branch with a name and a required Mainstream or Overlay role. One Mainstream per workspace.
  • Documents tree and file attach on a card.
  • Header search jumps to a card or document by id, title, summary, or body.
  • Workspace report export: Markdown, PDF, DOCX.
  • Timeline of object events.

Still growing. Persona-weighted home strips, theory diffs, falsify actions, and several card verbs named in the object model are not the product you get on first open. The catalog and the shell are there; those refinements are next, not hidden behind this page.
