An environment where thinking can evolve

The analogy

Git for thinking

Git does not tell programmers what code to write. It is the environment in which code can evolve: create, branch, experiment, compare, revise, merge, abandon, resurrect. Ideate does the same for thought.

A 15-year-old learning orbital mechanics, a scientist revising a theory, an inventor walking a design, and an analyst reconstructing a decision all use the same loop. The domain changes. The operating system does not.

In the workspace today

A thinking IDE, not a dashboard

The page is the graph. Chat is how you talk into it. Cards are typed nodes you can jump to by display id.

Typed cards

Thought, Concept, Unknown, Question, Hypothesis, Evidence, Evaluation, Theory, and the rest of the catalog share one chrome.

Zoomable graph

ngDiagram canvas in the center. Relationships are edges. Opening a node is a full page tab.

Persisted Explore

The entire conversation is stored. Explore materializes objects as you talk. You can edit, merge, delete, or undo.

Mainstream and overlays

One Mainstream branch per workspace. Overlay branches stay private until you merge them.

Jump search

Header search on display id, title, summary, and body. H-017 pans the camera to that card.

Docs, attachments, reports

A documents tree, files on cards, timeline, and export to Markdown, PDF, or DOCX.

Honest scope

What Ideate is — and what it is not

Ideate starts from

  • Here is what I am trying to understand
  • Here is a thought; help it become a concept, a hypothesis, evidence, maybe a theory
  • Walk the graph of what I already understand, then grow it
  • Here is how my thinking changed, and why

It is not

  • A ChatGPT / Grok / Claude skin (those are backends)
  • A competitor to Zotero or Notion on document storage
  • Software only for researchers
  • A phone-first authoring app in this version

Frequently asked

Questions people ask first

Is this the same as chatting with a model?

Chat is an input method. Objects, edges, versions, and the transcript survive the session. The graph is memory. Models are backends you can point at cloud APIs or a local Ollama / LM Studio URL.

Do I get a default workspace after signup?

No. You create a workspace per project and must choose a persona from a dropdown. Nothing is pre-selected.

Can a team share a workspace?

This lab build is a single-thinker workspace: one account, many personal projects. Team workspaces are described as a later Pro plan, not as something this deploy advertises as live.

Where does the data live?

On the operator’s PostgreSQL (Apache AGE + pgvector) and in the Java API. Sign-in is off in the current lab deploy. See Privacy and Security.
