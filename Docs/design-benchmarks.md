# Design benchmarks

These are **design references for us**, not sample projects in the app. The product starts from an **empty workspace**. No satellite, projector, Purana, or other prior graph is shipped.

| Benchmark | Persona emphasis | What it falsifies if it fails |
| --- | --- | --- |
| [Stationary Satellite Relays](./design-benchmark.md) | Explorer / Researcher | Cannot hold a speculative thought experiment that slowly becomes a theory |
| [Prism-Based Projector Feasibility](./design-benchmark-prism-projector.md) | Inventor | Cannot hold hardware feasibility: constraints, calculations, BOM versions, targets ≠ facts |
| Student physics (see [learning-mode.md](./learning-mode.md)) | Student | Cannot grow understanding without dumping answers |

Same loop under all three:

```text
HUMAN IDEA → QUESTION → EXPLORATION
  → Knowledge / Evidence / Experiment (or Calculation / Prototype)
  → UNDERSTANDING → CRITIQUE → VERSION → NEW QUESTION
```

We will try the real product from empty workspaces. If a construct only works on a pre-built demo graph, it is not a primitive.
