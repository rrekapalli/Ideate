# Analyst / strategist

**Persona:** Analyst  
**Related vertical:** [Consulting](./consulting.md) (firm-scale of the same job)  
**Also:** quantitative trading *as a decision*, strategy reviews, “why did we reject this?”

An analyst uses Ideate to **choose under uncertainty** and replay the reasoning later. The recommendation is not a slide; it is a Decision with a chain.

## Job

Home asks: *Why this decision, and what would change our mind?*

Success: traceable reasons, alternatives held in parallel (Debate / overlay), replay months later without hunting email.

Example workspaces: *Should we enter this market?*; trading research when the output is a position or rule; internal strategy; a consultant’s engagement before a dedicated Consultant lens exists.

## Lifecycle

```text
Question → competing hypotheses → evidence → analysis
  → critique → decision → outcome → revise the rule
```

| Step | Analyst |
| --- | --- |
| Think | If we do A, what must be true? |
| Explore | Walk the decision tree / workstreams |
| Connect | Data sources ↔ assumptions ↔ options |
| Question | What would change our mind? |
| Test | Analysis, scenarios, kill criteria |
| Revise | Update the live recommendation |
| Create | A decision (and later an outcome) |

## Killer features

- **Replay:** six months later, which hypothesis and evidence produced the call (same story as store closures in [consulting.md](./consulting.md)).
- **Unknown** and tagged speculation so a model is not treated as a fact.
- **Outcome** fed back onto the Decision (what actually happened).
- **Challenge mode** as the default pressure on load-bearing assumptions.

## Objects emphasized

Question, Hypothesis, Assumption, Evidence, Evaluation, Decision, Constraint, Claim, Critique. Trading: Calculation + Evidence on signals; still not a broker.

## What this is not

- A BI dashboard
- An Excel replacement
- Silent auto-trading
